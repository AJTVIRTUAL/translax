# Prompt logo/icône — TRANSLAX (monogramme "TX")

Basé sur la charte déjà visible dans l'app (captures/*.png) : fond très
sombre bleu-noir, wordmark blanc en majuscules espacées, accent en
dégradé bleu → cyan (bouton "Traduire" et barre de progression). Le
prompt ci-dessous reprend cette palette pour que l'icône soit cohérente
avec le logiciel.

À coller dans ChatGPT (l'anglais donne des résultats plus précis avec les
générateurs d'images, d'où la langue du prompt) :

---

```
Design a modern, minimalist desktop application icon featuring the bold
monogram letters "TX" (both letters must always be fully legible — either
interlocked cleanly or the T's vertical stroke doubling as part of the X).
Square format (1:1), centered composition, must stay clean and readable
at small sizes (down to 32x32 px) as well as large (256x256 px+).

Style: clean, geometric, professional, serious software/tech aesthetic —
think a polished developer or productivity tool, NOT playful, NOT
cartoonish, NOT a mascot. Sharp clean vector lines, flat illustration
style (no photorealism, no 3D render, no busy drop shadows). Rounded-
square app-icon container, similar to modern Windows 11 / macOS icon
conventions.

Color palette: deep dark navy-black background (hex #0d0f1a), with the
"TX" letters rendered in a smooth gradient from blue (#4a7dff) to cyan
(#4ce0d8). Optional very subtle lighter glow/gradient behind the letters
for depth — keep it minimal, no extra colors.

Typography: bold geometric sans-serif, uppercase, tight letter-spacing,
merged into a single confident monogram mark — no extra text, no
tagline, no additional icons or symbols cluttering the composition.

Composition: perfectly centered, generous even padding around the
letters, high resolution, crisp flat vector illustration look suitable
for use as a Windows desktop application icon (.ico) for a local
document-translation software called "TRANSLAX".
```

---

## Variante courte (si le prompt long est tronqué / pour itérer vite)

```
Flat vector app icon, dark navy background (#0d0f1a), bold geometric
monogram "TX" in blue-to-cyan gradient (#4a7dff to #4ce0d8), centered,
minimalist, professional software icon style, square format, no text,
no extra elements.
```

## Notes

- Si le rendu de ChatGPT/DALL-E te donne un "T" et un "X" trop séparés ou
  illisibles ensemble, rajoute dans le prompt : *"the T and X should share
  a common stroke, like a proper monogram logo, not two separate
  letters side by side"*.
- Pour obtenir plusieurs pistes différentes d'un coup, demande explicitement
  "give me 4 different monogram layout variations" dans le même message.
- Une fois un logo choisi, pense à demander une version fond transparent
  (PNG) séparément pour la conversion en `.ico` multi-résolutions.
