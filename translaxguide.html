01 — Le logiciel

Un traducteur de livres qui ne quitte jamais ta machine

TRANSLAX prend un document en anglais (PDF, TXT ou MD) et en ressort une version française avec de vrais paragraphes — pas un pavé de texte. Le modèle de traduction (NLLB-200, par Meta AI) tourne localement : rien de ce que tu traduis ne part sur internet.

Import

PDF, TXT ou MD — détection et découpage automatiques.

Langues

Anglais → Français par défaut, 18 langues au total.

6 profils de modèle

600M, 1.3B, 3.3B, 600M Turbo (CTranslate2), OPUS-MT et MADLAD-400. Ce test : 600M — Rapide.

Progression live

%, vitesse, ETA — le fichier se remplit en direct.

Sortie auto

03 — Pourquoi toi

Ton PC contre le mien

Ma machine traduit tout au CPU — pas de carte graphique dédiée. La tienne a une RTX. Sur ce type de calcul, une carte NVIDIA change complètement la donne, si elle est bien utilisée par le logiciel — voir l'étape CUDA plus bas.

05 — Installation

Dix minutes de config

Un TRANSLAX.exe autonome existe maintenant pour un usage courant, mais ne l'utilise pas pour ce test : il embarque une version de PyTorch figée au moment de sa construction, sans le contrôle fin nécessaire pour activer ta RTX. Installe depuis les sources, comme ci-dessous — c'est le seul moyen de garantir que ta carte graphique est vraiment utilisée.

  1. Dézippe le dossier reçu, où tu veux sur ton disque.
  2. Installe Python 3.11+ depuis python.org/downloads — coche « Add python.exe to PATH ».
  3. Ouvre un terminal dans le dossier et crée un environnement virtuel — ça garde les dépendances de TRANSLAX isolées du reste de ta machine : 
    python -m venv .venv
.venv\Scripts\activate
    L'invite doit maintenant afficher (.venv) — garde-le actif pour toutes les commandes suivantes, y compris au §10.
  4. Installe les dépendances : 
    pip install -r requirements.txt
Étape critique — ne pas sauter

L'installation ci-dessus donne une version de PyTorch qui n'utilise pas ta carte NVIDIA par défaut. Sans l'étape suivante, ta RTX reste inactive et le test perd tout son intérêt.

Tape nvidia-smi dans un terminal — note la ligne CUDA Version en haut à droite. Va ensuite sur pytorch.org/get-started/locally, choisis Windows / Pip / la version CUDA la plus proche, et lance la commande donnée. Exemple typique :

pip uninstall torch
pip install torch --index-url https://download.pytorch.org/whl/cu124

Puis vérifie :

python -c "import torch; print(torch.cuda.is_available())"

True ? Ta carte sera utilisée automatiquement, rien d'autre à faire.

  1. Lance l'application : 
    python main.py
    Premier lancement = téléchargement du modèle (~2,5 Go), une seule fois.
06 — Réglages du test

Trois réglages à vérifier

  • Modèle : « 600M — Rapide » — celui utilisé sur ma machine de référence, indispensable pour comparer les mêmes conditions.
  • Langue source = Anglais — vérifie qu'elle correspond bien à la langue réelle du fichier avant de lancer.
  • Langue cible = Français.
Nouveau — bonus optionnel

TRANSLAX propose maintenant un 4e profil, « 600M — Turbo (CTranslate2) » : mêmes poids que « 600M — Rapide », mais servis par un moteur d'inférence optimisé. Mesuré sur ma machine de référence (CPU seul, sans GPU) : environ 13× plus rapide, avec une sortie quasi identique.

Une fois le test principal terminé (600M — Rapide), si tu as un peu de temps devant toi, relance la même traduction avec ce profil Turbo et note le temps — pas obligatoire, mais ce serait une donnée intéressante en plus.

08 — Pendant que ça tourne

Laisse tourner, reviens plus tard

Même accéléré, un livre de 300+ pages prend du temps — de quelques dizaines de minutes à plusieurs heures selon le matériel. Ferme l'appli si besoin, elle reprend automatiquement. Pour confirmer que la RTX travaille : Gestionnaire des tâches → Performance → GPU, et regarde si l'usage grimpe pendant la traduction.

09 — À la fin

Ce qui m'intéresse en retour

  • Titre du livre + nombre de pages / mots
  • Temps total (ou vitesse moyenne en s/segment, affichée dans l'appli)
  • Confirmation que torch.cuda.is_available() renvoyait True
  • Une capture d'écran une fois « Terminé »
  • Le fichier .md obtenu
Confidentialité

Le contenu du livre ne quitte jamais ta machine. Seul le modèle NLLB (public, générique) est téléchargé au premier lancement — jamais ton document.

10 — Pour aller plus loin (optionnel)

En faire un vrai raccourci sur ton bureau

Si tu gardes TRANSLAX après le test et que tu préfères un double-clic à un terminal à chaque fois, tu peux le transformer toi-même en .exe autonome — pyinstaller est déjà installé (il fait partie de requirements.txt).

  1. Ferme toutes les fenêtres TRANSLAX ouvertes avant de lancer l'empaquetage — sinon PyInstaller échoue avec une erreur de permission sur le fichier .exe.
  2. Depuis le dossier du projet, avec le (.venv) activé (rouvre un terminal puis .venv\Scripts\activate si besoin), lance : 
    pyinstaller --onefile --windowed --name TRANSLAX --icon ui\icon.ico ^
    --add-data "ui\styles.qss;ui" --add-data "ui\icon.ico;ui" main.py
  3. Résultat : dist\TRANSLAX.exe, environ 307 Mo — déplace-le où tu veux (bureau, menu Démarrer).
À savoir

Le modèle NLLB (~2,4 Go) n'est pas inclus dans l'.exe — il reste dans le cache Hugging Face partagé, comme en mode développement.

Cet .exe garde la configuration PyTorch de l'environnement où tu l'as construit — empaqueté après avoir activé CUDA (§05), la RTX continuera d'être utilisée normalement une fois packagé.
